〈アイデア〉

敵が水門の操作レバーを塞いでいるため、洪水を起こすには敵との対抗に勝利しなければならない。

DEXもしくはSTR対抗に成功した後、重機械操作x2に成功すれば水門を開くことができる（敵のDEXは14、STRは11）。水門の解除方法について構造資料を読んでいる場合、成功率に50%のプラス補正がもらえる（重機械操作10の場合20＋50＝70%で振ることができる）。

しかし、大雨が降っているため、洪水に飲み込まれる前に脱出する必要がある。6ラウンド以内に脱出宣言をすれば生還可能。

水門が開いた状態で7ラウンド目以降も街にいた場合は洪水に巻き込まれてロストとなる。水門が開いていなければ洪水は起きないため、ラウンド関係なく街から脱出することが可能である。一度水門を開けた後、再度閉じるためには逆回転させる必要があるが、洪水の圧力もあるため難しい。
